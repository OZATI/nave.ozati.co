Protocolos de Integração do Nave AI

Documentação completa para conectar agentes de IA autônomos, sistemas externos e fluxos automatizados ao ecossistema Nave AI e OZATI.

1. Protocolo de Chamada por Deep Link (URL Params)

Agentes de IA e sistemas web podem invocar o Nave Chat enviando tarefas ou prompts pré-formatados diretamente pela URL. 

https://chat.ozati.co/?prompt={encoded_prompt}&send=1&model={model_id}
  • prompt: Mensagem, instrução ou pergunta codificada em URI.
  • send=1: Força a submissão e o início do streaming imediato da resposta.
  • model: Modelo específico (ex: anthropic/claude-3.7-sonnet, openai/gpt-4o, deepseek/deepseek-r1).
  • system: Prompt de sistema customizado para instruir o comportamento do modelo.

2. Model Context Protocol (MCP)

O Nave AI implementa suporte ao padrão aberto Model Context Protocol da Anthropic. Isso permite conectar modelos de fronteira com ferramentas locais de terminal, bancos de dados corporativos e APIs do ecossistema OZATI. 

{
  "mcpServers": {
    "ozati-nave": {
      "command": "npx",
      "args": ["-y", "@ozati/nave-mcp-server"],
      "env": {
        "NAVE_ENDPOINT": "https://chat.ozati.co"
      }
    }
  }
}

Ferramentas padrão disponibilizadas via servidor MCP:

  • nave_web_search: Busca na web em tempo real e extração de contexto limpo.
  • nave_summarize_url: Processamento e síntese profunda de páginas remotas.
  • nave_clinic_kiosk: Consulta a agendamentos e retornos no módulo hospitalar OZATI.

3. Recursos de Máquina para LLMs & Agentes

Disponibilizamos endpoints padronizados para agentes de busca e raciocínio programático:

openapi.json

Especificação OpenAPI 3.1.0 para leitura por ferramentas de automação.

llms.txt

Manifesto com diretrizes "When to Use This" no padrão llmstxt.org.

llms-full.txt

Documentação técnica integral consumível via Accept: text/markdown.

agent-instructions.md

Regras e árvore de decisão para agentes autônomos de IA.

sitemap.xml

Índice completo de rotas e recursos indexáveis do subdomínio.

robots.txt

Declaração de liberação irrestrita para rastreadores e bots de IA.

4. Segurança e Arquitetura Local-First

Ao integrar com o Nave AI, desenvolvedores contam com garantias estruturais de conformidade:

  • Chaves Próprias (BYOK): As chaves de API nunca são enviadas aos nossos servidores; a conexão parte do navegador diretamente para a API dos provedores.
  • Sem Telemetria Oculta: Código estático auditável sem rastreadores de terceiros ou pixels publicitários.
  • CORS Aberto: Cabeçalhos Access-Control-Allow-Origin: * habilitados para consultas de recursos públicos por agentes.
